# Student Registration Form

A simple and beginner-friendly Student Registration Form built using HTML, CSS, and JavaScript.

## 📌 About the Project

This project demonstrates how to create a student registration form with a simple design and basic form validation. It allows users to enter their details and displays a success or error message when they click the Register button.

## ✨ Features

- Student name input
- Email input
- Register number input
- Department selection
- Gender selection
- Basic form validation
- Success and error messages
- Simple and user-friendly design

## 🛠️ Technologies Used

- **HTML5** – Creates the form structure.
- **CSS3** – Styles the form.
- **JavaScript** – Validates inputs and displays messages.

## 📂 Project Structure

```text
Student-Registration-Form/
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter the student details.
5. Click the **Register** button to see the validation message.

You can also use the Live Server extension in Visual Studio Code.

## 📸 Output

The form allows users to enter student details. It displays an error message if any required field is empty and a success message when all fields are filled.

## 🎯 Objective

The objective of this project is to understand the basics of HTML forms, CSS styling, JavaScript event handling, and form validation.
